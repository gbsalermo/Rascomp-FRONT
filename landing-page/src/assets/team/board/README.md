# Fotos da Diretoria

Adicione aqui as fotos individuais da diretoria.

Formatos aceitos:

```text
.jpg
.jpeg
.png
.webp
.avif
```

A ordem é definida alfabeticamente pelo nome do arquivo e associada aos 6 cargos
na ordem exibida pela Landing.

Recomendação:

```text
01-presidente.jpg
02-vice-presidente.jpg
03-tesouraria.jpg
04-secretaria.jpg
05-diretoria-tecnica.jpg
06-comunicacao.jpg
```

Os nomes e cargos continuam definidos no componente até a Gestão de Mídia/CMS.
