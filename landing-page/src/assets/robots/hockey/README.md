# Hockey

Adicione nesta pasta as imagens dos robôs da categoria **Hockey**.

Formatos aceitos:

```text
.jpg
.jpeg
.png
.webp
.avif
```

## Nome do robô

O nome do arquivo vira automaticamente o título mostrado na Landing.

Exemplos:

```text
01-vespa.jpg       -> Vespa
02-trovão.webp     -> Trovão
03-rasbot.png      -> Rasbot
```

O prefixo numérico controla a ordem e não aparece no título.

A section **Nossos Robôs** descobre os arquivos automaticamente; não é necessário editar o componente para adicionar um novo robô.
