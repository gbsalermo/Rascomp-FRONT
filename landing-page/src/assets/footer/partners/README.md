# Logos de parceiros do Footer

Adicione aqui as logos institucionais utilizadas no bloco **Apoio e parceiros**.

Nomes esperados:

```text
ufrb.png
ieee.png
cetec.png
```

Também são aceitos:

```text
.jpg
.jpeg
.webp
.avif
.svg
```

O nome-base do arquivo deve permanecer exatamente:

```text
ufrb
ieee
cetec
```

A logo da **IEEE RAS** já é reaproveitada automaticamente de:

```text
landing-page/public/ieee-ras-official.png
```

Se uma imagem não existir, o card mantém o nome textual como fallback.

Durante o desenvolvimento, se uma logo recém-adicionada não aparecer imediatamente, reinicie o `npm run dev` para o Vite reconstruir o `import.meta.glob`.
