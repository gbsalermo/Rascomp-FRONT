# Landing Page — RASCOMP

Aplicação pública do RASCOMP/RRC.

## Responsabilidade

Esta aplicação será responsável por apresentar a RAS/UFRB, a competição e suas informações públicas, sem carregar dependências ou regras administrativas da área de gestão.

## Escopo previsto

- Hero/apresentação;
- RAS UFRB;
- sobre a competição;
- modalidades;
- eventos;
- cronograma;
- diretoria/organização;
- contato;
- chamada para inscrições.
